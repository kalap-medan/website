KALAP Management System v2.2.14

Perbaikan yang termasuk dalam rilis ini:

1. Notifikasi role/permission yang berasal dari listener Firestore setelah aksi reset seluruh sistem atau penghapusan berhasil tidak lagi ditampilkan sebagai kegagalan aksi. Kesalahan langsung dari proses reset/penghapusan tetap ditampilkan apabila operasinya benar-benar gagal.
2. Input stok manual dapat ditujukan ke tanggal mendatang. Catatan disimpan sebagai jadwal dan tidak menambah saldo hari berjalan. Saat tanggal bisnis target dimulai, proses pergantian hari yang sudah ada mengaktifkan saldo terjadwal. Tanggal lampau tetap ditolak.
3. Ringkasan dashboard dan rincian saat tanggal grafik diklik menghitung stok masuk berdasarkan total unit, bukan jumlah menu. Input manual dan pengajuan mitra ikut dihitung; perubahan jumlah batch memakai editedQty. Unit terjual dihitung dari jumlah item pada transaksi POS, dan sisa dihitung dari stok tersedia dikurangi unit terjual.
4. Angka stok masuk, terjual, dan sisa di popup rincian grafik memakai perhitungan harian yang sama dengan dashboard.
5. Mekanisme reset angka harian pada kartu Manajemen Mitra sudah tersedia pada kode sebelumnya. Mekanisme itu tidak diubah dalam rilis ini.

Pemasangan:
- Ganti index.html dan service-worker.js di root hosting.
- Publikasikan firestore.rules ke project Firebase agar input stok terjadwal mendapat izin Rules yang sesuai.
- Pertahankan manifest.webmanifest dan folder icons/ yang digunakan oleh hosting saat ini.
- Lakukan hard refresh setelah deployment.

Catatan verifikasi:
- Pemeriksaan sintaks JavaScript dilakukan pada index.html dan service-worker.js.
- Firestore Rules perlu dipublikasikan ke project Firebase untuk verifikasi di lingkungan aplikasi; pemeriksaan lokal tidak melakukan deployment atau mengubah data produksi.
