KALAP Management System v2.2.8

Perbaikan stok harian mitra
- Saldo stok menu mitra tidak lagi terbawa lintas hari. Saldo hari berjalan dibangun dari pergerakan stok pada tanggal itu saja.
- Berlaku untuk input stok manual Admin/SPV dan persetujuan pengajuan stok mitra.
- Saat closing, sisa stok dicatat pada ringkasan closing lalu saldo operasional menu mitra dikosongkan menjadi 0.
- Pengajuan pending/revisi tanggal sebelumnya ditandai kedaluwarsa, lock dilepas, dan mitra dapat mengajukan stok baru.
- Badge Pengajuan Stok hanya menghitung menu pending/revisi dari tanggal berjalan. Riwayat hari sebelumnya tetap tersimpan.
- Pembuatan pengajuan dan perubahan pengajuan diblokir ketika closing sedang berjalan atau sudah selesai.
- Detail stok per menu pada popup grafik dashboard dihapus.
- Firestore Rules diperbarui untuk mendukung tanggal bisnis stok, rollover harian, kedaluwarsa pengajuan, dan penguncian saat closing.
- Cache PWA diperbarui ke kalap-shell-v2.2.8.

PENTING: Publikasikan firestore.rules dari paket ini di Firebase Console > Firestore Database > Rules sebelum menggunakan aplikasi v2.2.8.
