KALAP Management System v2.2.13

Fitur Reset Seluruh Sistem khusus Superadmin
- Menambahkan satu tombol Reset seluruh sistem pada halaman Menu & Persediaan, hanya terlihat untuk Superadmin aktif.
- Konfirmasi wajib mengetik RESET SEMUA.
- Menghapus seluruh data operasional: transaksi, cashflows, penjualan mitra, pergerakan stok, pengajuan stok, lock pengajuan, payout, data closing, dan ringkasan closing.
- Mengatur saldo operasional semua menu menjadi 0, menghapus lastMovementId, dan mengatur tanggal stok mitra ke hari reset. Identitas katalog menu (nama, harga, barcode/QR, status, dan tautan mitra) tetap dipertahankan.
- Data mitra, akun/login users, arsip menu/mitra, konfigurasi Firebase, dan catatan otorisasi reset tetap dipertahankan agar akses dan katalog tidak hilang.
- Penghapusan dilakukan per batch dengan manifest otorisasi yang diperbarui tiap batch, sehingga tidak bergantung pada satu batch 500-write atau satu manifest yang besar.
- Kegagalan setelah beberapa batch ditandai sebagai parsial dengan jumlah batch yang sudah berjalan; jalankan ulang setelah memeriksa hasilnya agar menyelesaikan pembersihan data yang tersisa.
- Rules baru menggunakan systemResetAuthorizations/active dan hanya memperbolehkan Superadmin aktif.

Pemasangan
- Ganti index.html dan service-worker.js di root GitHub Pages.
- Publikasikan firestore.rules v2.2.13 ke project Firebase yang sama sebelum mencoba tombol.
- Pertahankan folder icons/ dan file manifest.webmanifest.
