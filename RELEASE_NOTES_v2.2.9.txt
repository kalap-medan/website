Perbaikan Reset Harian untuk Superadmin/SPV
- Sebelum memulai Reset Harian, aplikasi memverifikasi profil users/{UID} langsung dari Firestore Server.
- Reset mensyaratkan active == true dan role == superadmin atau spv pada profil Firestore.
- Dokumen otorisasi reset dipertahankan berstatus running selama batch utama berjalan; status completed ditulis setelah batch utama berhasil, dalam operasi terpisah.
- Pesan penolakan Firestore diperjelas agar tidak langsung menyatakan role login salah.
- Tidak ada perubahan fitur lain.

Firestore Rules:
- Tidak ada perubahan logika izin dari v2.2.8. Pastikan Rules v2.2.8 sudah dipublikasikan di project Firebase yang sama.
